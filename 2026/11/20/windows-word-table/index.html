Word 效率技巧：使用 VBA 宏一键批量规范所有表格格式

发表于2026-11-20|更新于2026-11-20|technology
|字数总计:990|阅读时长:3分钟|阅读量:

在撰写长篇报告、毕业论文或技术文档时，文档中往往包含几十个表格。如果逐一手动调整它们的字体大小、页面宽度和对齐方式，不仅耗时耗力，还容易出现格式不统一的问题。

利用 Word 内置的 VBA 宏功能，只需几秒钟就能批量搞定全文档的表格排版。下面分别介绍单项调整代码以及直接可用的“三合一”完整脚本。

操作步骤（通用）

无论使用下方哪一段代码，操作流程完全一致：

  1. 打开 VBA 编辑器：在 Word 文档中按下快捷键 Alt + F11（部分笔记本电脑需按 Fn + Alt + F11）。
  2. 插入模块：在顶部菜单栏点击 插入 > 模块，右侧会弹出一个空白的代码编辑窗口。
  3. 粘贴代码：将下方所需的 VBA 代码复制并粘贴到空白窗口中。
  4. 运行脚本：按 F5 键（或点击工具栏上的绿色三角形 运行 按钮），等待弹出完成提示框即可关闭编辑器。
