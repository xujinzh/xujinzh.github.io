Linux 下使用 7z 进行带密码压缩与解压的完整指南

在 Linux 环境下管理文件时，7z 凭借其极高的压缩比和强大的加密功能，成为了常用的压缩工具之一。本文将为您详细介绍如何在 Linux 终端中使用 7z 命令进行带密码的压缩、解压以及安全加密技巧。

默认情况下 7z 会解压到当前路径。如果想释放到指定文件夹，可以使用 -o 参数（注意：**-o 与路径之间同样不能有空格**）：

3. 核心参数速查表

参数 功能说明 避坑提示
a 添加文件到压缩包 (Archive) 后面接压缩包名
x 解压并保持目录结构 (eXtract) 推荐使用，不会打乱文件夹
-p 设置或输入密码 (Password) 后面紧跟密码，不能加空格
-mhe=on 开启头部加密 (Header Encryption) 隐藏压缩包内的文件名列表
-o 指定输出目录 (Output) 后面紧跟路径，不能加空格

总结

  • 临时用用：7z a -p123456 archive.7z folder
  • 追求安全：7z a -p -mhe=on archive.7z folder
  • 日常解压：7z x archive.7z
